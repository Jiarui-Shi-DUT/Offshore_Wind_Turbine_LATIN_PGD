# PGD 新模态的最优缩放：原理、必要性与当前实现说明

## 1. 文档目的

本文档用于记录 LATIN–PGD 第 5.1 节复现过程中，对“新增 PGD 模态为什么需要最优缩放”的理解与实现依据，重点回答以下问题：

1. 什么是最优缩放；
2. 为什么交替固定点迭代已经收敛后，新增模态的原始幅值仍可能不合适；
3. 为什么直接采用未经缩放的新模态可能使残差增大；
4. 最优缩放如何确定新模态的贡献幅值；
5. 该处理与论文原始算法之间是什么关系；
6. 当前 Python 实现中应如何准确描述这一稳定化措施。

本文档对应当前开发分支：

```text
feature/hybrid-convergence-criteria
```

相关实现主要位于：

```text
latin/pgd_enrichment.py
latin/pgd_time_update.py
latin/pgd_global_stage.py
```

## 2. 最直观的理解

可以把最优缩放理解为：

> 新 PGD 模态已经找到了一个有用的空间–时间修正模式，但还需要确定该模式在总修正中应占多大权重。

固定点迭代主要回答：

> 应沿什么空间–时间模式修正？

最优缩放进一步回答：

> 沿这个模式修正多少最合适？

因此可以概括为：

```text
固定点迭代负责确定修正方向；
最优缩放负责确定修正幅值。
```

---

## 3. 新增 PGD 模态在做什么

设当前 PGD 近似包含 $`M`$ 个模态：

```math
u_M(x,t)
=
\sum_{m=1}^{M}
X_m(x)\lambda_m(t).
```

将当前近似代入全局阶段方程后，仍会存在一个未被消除的残差：

```math
r(x,t).
```

为了进一步降低残差，需要构造一个新的空间–时间分离项：

```math
c(x,t)
=
X_{M+1}(x)\lambda_{M+1}(t).
```

加入该模态后，新的近似写为：

```math
u_{M+1}(x,t)
=
u_M(x,t)
+
\alpha c(x,t).
```

其中 $`\alpha`$ 是新增模态的整体贡献系数。

若直接采用固定点迭代得到的原始模态，相当于默认：

```math
\alpha=1.
```

但 $`\alpha=1`$ 并不一定是当前残差下的最优选择。

---

## 4. 为什么空间函数与时间函数本身存在尺度不唯一性

一个 PGD 模态由空间函数和时间函数的乘积组成：

```math
c(x,t)
=
X(x)\lambda(t).
```

该分离表示存在天然的尺度不唯一性。例如：

```math
X(x)\lambda(t)
=
\left(10X(x)\right)
\left(0.1\lambda(t)\right).
```

两种写法表示的是完全相同的空间–时间场。

因此，在交替固定点迭代中，程序通常会：

1. 固定时间函数，求空间函数；
2. 对空间函数进行归一化；
3. 将尺度转移给时间函数；
4. 固定空间函数，更新时间函数；
5. 重复上述过程直到候选模态变化足够小。

这种归一化能够稳定数值尺度，但不能自动保证：

> 该模态相对于当前全部已有模态和当前全时空残差的整体贡献幅值已经最优。

---

## 5. 固定点收敛究竟说明了什么

设第 $`k`$ 次交替更新得到的候选修正场为：

```math
c_k(x,t).
```

固定点迭代通常通过相邻两次候选场的相对变化判断收敛，例如：

```math
\eta_k
=
\frac{
\left\|c_k-c_{k-1}\right\|
}{
\left\|c_k\right\|
}.
```

当：

```math
\eta_k
\leq
\eta_{\mathrm{tol}}
```

时，可以认为：

> 按照当前的空间更新、时间更新、归一化和正交化规则，候选模态已经基本不再变化。

但是，这并不等价于：

```math
\left\|r+c_k\right\|
=
\min_c
\left\|r+c\right\|.
```

也不严格等价于：

```math
\left\|r+c_k\right\|
<
\left\|r\right\|.
```

因此，“固定点已经收敛”只能说明候选模态对当前交替更新映射已经稳定，不能单独保证将其以原始幅值加入后一定降低完整时空残差。

---

## 6. 为什么原始幅值可能不适合当前多模态残差

### 6.1 候选模态不是在空白基底上构造的

第一个 PGD 模态通常用于捕捉残差中的主导空间–时间结构。

当构造第二个或第三个模态时，当前近似已经包含：

```math
u_M(x,t)
=
\sum_{m=1}^{M}
X_m(x)\lambda_m(t).
```

此时新模态面对的不是原始外载或原始响应，而是：

> 已有多个模态修正后仍然剩余的残差。

这个剩余残差通常具有更复杂的空间–时间结构，并且可能与已有模态之间存在较强相关性。

因此，新模态虽然能够捕捉一个有用方向，但其原始归一化幅值未必适合当前多模态组合。

---

### 6.2 空间更新、时间更新和最终残差评价的目标不完全一致

当前实现中，空间函数和时间函数通过交替方式分别更新。

空间子问题是在固定时间函数的条件下求解；时间子问题是在固定空间函数的条件下求解。

但是最终是否接受新模态，是根据完整时空域中的加权残差范数判断的。

也就是说：

```text
空间子问题的局部最优
+
时间子问题的局部最优
```

并不必然等于：

```text
完整空间–时间残差范数下的联合最优
```

这是一种典型的块坐标交替优化特征。

即使空间更新和时间更新已经互相稳定，候选模态在完整残差范数下仍可能整体偏大、偏小，甚至符号相反。

---

### 6.3 时间函数采用逐时间步更新

当前时间函数并不是一次性联合求解所有时间系数，而是按照时间顺序更新：

```math
\lambda_1
\rightarrow
\lambda_2
\rightarrow
\lambda_3
\rightarrow
\cdots
\rightarrow
\lambda_N.
```

一个典型的时间离散残差可表示为：

```math
r_n
=
\bar{\varepsilon}^{p}
\frac{
\lambda_n-\lambda_{n-1}
}{
\Delta t
}
-
H_{\sigma,n}\bar{\sigma}\lambda_n
-
f_n.
```

其中 $`\lambda_n`$ 不仅影响当前时刻的残差 $`r_n`$，还会通过时间导数影响下一时刻的残差 $`r_{n+1}`$。

例如：

```math
r_1
=
r_1(\lambda_1,\lambda_0),
```

```math
r_2
=
r_2(\lambda_2,\lambda_1),
```

```math
r_3
=
r_3(\lambda_3,\lambda_2).
```

当程序求解 $`\lambda_1`$ 时，主要处理当前时间步的离散方程，但 $`\lambda_1`$ 还会影响后续的 $`r_2`$。

因此，逐时间步更新得到的是：

> 按时间顺序依次满足离散更新规则的时间函数。

它不完全等同于一次性求解：

```math
\min_{
\lambda_1,\lambda_2,\ldots,\lambda_N
}
\sum_{n=1}^{N}
\left\|r_n\right\|^2.
```

因此，时间函数的整体形状可以是有效的，但其全局幅值仍可能不是完整时空残差下的最优幅值。

---

### 6.4 一个时间系数需要同时拟合多个空间位置

在实际有限元离散中，某一时刻的时间系数 $`\lambda_n`$ 是一个标量，但它需要同时作用于所有单元或所有空间积分点。

残差可写成：

```math
r_n(x)
=
\bar{\varepsilon}^{p}(x)\dot{\lambda}_n
-
H_{\sigma}(x,t_n)\bar{\sigma}(x)\lambda_n
-
f(x,t_n).
```

由于不同位置具有不同的：

- 材料参数；
- 搜索方向；
- 损伤水平；
- 应力状态；
- 剩余残差分布；

一个标量 $`\lambda_n`$ 通常无法使所有空间位置的残差同时为零，只能得到某种加权意义下的折中解。

这个折中解在逐时间步、逐子问题更新后，不一定恰好具有最优整体尺度。

---

### 6.5 正交化也可能改变候选模态的有效幅值

为了避免新增 PGD 模态重复已有模态的信息，程序可能对候选空间函数执行正交化。

正交化会移除与已有基底平行的分量，因此候选模态经过正交化后：

- 空间形状发生调整；
- 模态有效能量发生变化；
- 原来时间函数携带的幅值不一定仍与新的空间函数匹配。

因此，即使正交化前的候选模态幅值合理，正交化后也可能需要重新确定整体尺度。

---

## 7. “方向正确、幅值不合适”应如何准确理解

这里的“方向”不是指一个简单的有限维向量方向，而是指新增模态的空间–时间分布模式：

```math
c(x,t)
=
X(x)\lambda(t).
```

它包含以下信息：

- 哪些空间区域需要修正；
- 哪些时间区间需要修正；
- 修正的正负号如何变化；
- 周期内的变化规律；
- 空间场与时间场的主要关联结构。

固定点迭代通常能够较好地识别这些模式。

所谓“幅值不合适”，是指：

> 该空间–时间模式在总解中应占的整体权重并不一定等于 1。

例如，候选模态形状正确，但最佳更新实际上应为：

```math
0.3c(x,t),
```

而不是：

```math
1.0c(x,t).
```

如果直接加入完整的 $`c(x,t)`$，就可能发生修正过度。

## 8. 最优缩放的数学定义

设当前残差为：

```math
r(x,t),
```

候选 PGD 修正方向为：

```math
c(x,t).
```

加入缩放系数后，新残差写成：

```math
r_{\mathrm{new}}
=
r+\alpha c.
```

目标是在当前候选方向上选择一个标量 $`\alpha`$，使完整时空域中的加权残差范数最小：

```math
\alpha^\ast
=
\underset{\alpha}{\operatorname{arg\,min}}
\left\|
r+\alpha c
\right\|_{H_\sigma^{-1}}^2.
```

定义加权内积：

```math
\left\langle a,b\right\rangle_{H_\sigma^{-1}}
=
\int_{0}^{T}
\int_{\Omega}
\frac{
a(x,t)b(x,t)
}{
H_\sigma(x,t)
}
\,\mathrm{d}\Omega
\,\mathrm{d}t.
```

目标函数为：

```math
J(\alpha)
=
\left\langle
r+\alpha c,
r+\alpha c
\right\rangle_{H_\sigma^{-1}}.
```

展开后得到：

```math
J(\alpha)
=
\left\langle r,r\right\rangle
+
2\alpha
\left\langle r,c\right\rangle
+
\alpha^2
\left\langle c,c\right\rangle.
```

对 $`\alpha`$ 求导：

```math
\frac{
\mathrm{d}J
}{
\mathrm{d}\alpha
}
=
2\left\langle r,c\right\rangle
+
2\alpha
\left\langle c,c\right\rangle.
```

令导数为零：

```math
\frac{
\mathrm{d}J
}{
\mathrm{d}\alpha
}
=
0,
```

得到最优缩放系数：

```math
\alpha^\ast
=
-
\frac{
\left\langle r,c\right\rangle_{H_\sigma^{-1}}
}{
\left\langle c,c\right\rangle_{H_\sigma^{-1}}
}.
```

---

## 9. 为什么这一公式能够找到最佳幅值

目标函数 $`J(\alpha)`$ 是关于 $`\alpha`$ 的二次函数：

```math
J(\alpha)
=
A\alpha^2
+
B\alpha
+
C,
```

其中：

```math
A
=
\left\langle c,c\right\rangle_{H_\sigma^{-1}}
\geq0.
```

只要候选模态不是零模态，就有：

```math
A>0.
```

因此 $`J(\alpha)`$ 是开口向上的凸二次函数，存在唯一最小值。

$`\alpha^\ast`$ 正是该抛物线最低点对应的横坐标。

所以最优缩放不是经验调整，而是在当前候选模态方向上的解析一维最小化。

---

## 10. 为什么最优缩放能够保证残差不增大

不加入新模态相当于：

```math
\alpha=0.
```

由于 $`\alpha^\ast`$ 是当前方向上的最优点，因此：

```math
J(\alpha^\ast)
\leq
J(0).
```

也就是：

```math
\left\|
r+\alpha^\ast c
\right\|_{H_\sigma^{-1}}
\leq
\left\|
r
\right\|_{H_\sigma^{-1}}.
```

因此，经过最优缩放后，新增模态至少不会比完全不加入该模态更差。

需要注意，该结论只表示：

> 在当前候选方向 $`c`$ 上，$`\alpha^\ast`$ 是最佳幅值。

它不表示当前候选方向是所有可能空间–时间方向中的全局最优方向。

---

## 11. 不同缩放系数的含义

| 最优系数 | 含义 |
|---|---|
| $`\alpha^\ast=1`$ | 原始模态幅值恰好合适 |
| $`0<\alpha^\ast<1`$ | 候选方向有效，但原始幅值过大 |
| $`\alpha^\ast>1`$ | 候选方向有效，但原始幅值偏小 |
| $`\alpha^\ast<0`$ | 候选模态原始符号与降低残差的方向相反 |
| $`\alpha^\ast\approx0`$ | 候选模态与当前残差近似正交，贡献很小 |
| $`\langle c,c\rangle\approx0`$ | 候选模态接近零模态，不应接受 |

## 12. 当前计算中为什么必须增加这一步

在第 5.1 节复现过程中，曾出现以下现象：

1. 第二个 PGD 模态的交替固定点过程已经达到内部收敛条件；
2. 但直接采用原始幅值加入该模态后，完整加权残差反而增大；
3. 说明候选模态包含有效空间–时间结构，但其原始贡献幅值与当前多模态残差不匹配。

缩放前，候选模态使残差从：

```math
\left\|r\right\|
=
40.1190
```

增大到：

```math
\left\|r_{\mathrm{new}}\right\|
=
55.0036.
```

相对残差为：

```math
\frac{
55.0036
}{
40.1190
}
=
1.3710.
```

即残差增加约：

```math
37.1\%.
```

经过最优缩放后：

```math
\left\|r_{\mathrm{new}}\right\|
=
37.5552.
```

对应：

```math
\frac{
37.5552
}{
40.1190
}
=
0.9361.
```

残差降低约：

```math
6.39\%.
```

这说明最优缩放将一个原本会使残差增大的候选模态，调整为能够有效降低残差的模态。

## 13. 程序中具体缩放了什么

若新增塑性应变修正写成：

```math
\Delta\varepsilon^p(x,t)
=
X_{\varepsilon}(x)\lambda(t),
```

其对应的塑性应变率为：

```math
\Delta\dot{\varepsilon}^{p}(x,t)
=
X_{\varepsilon}(x)\dot{\lambda}(t).
```

计算出 $`\alpha^\ast`$ 后，程序同步执行：

```math
\lambda(t)
\leftarrow
\alpha^\ast\lambda(t),
```

以及：

```math
\dot{\lambda}(t)
\leftarrow
\alpha^\ast\dot{\lambda}(t).
```

从而使整个新模态统一变为：

```math
c(x,t)
\leftarrow
\alpha^\ast c(x,t).
```

该操作不会改变：

- 空间模态的基本形状；
- 时间函数的相对变化规律；
- 修正主要发生的时间区间；
- 修正主要作用的空间区域。

它只改变该模态在总解中的整体贡献大小。

## 14. 最优缩放与线搜索的关系

该方法与非线性优化中的“搜索方向 + 线搜索”具有相同思想。

在一般优化中：

1. 先确定搜索方向；
2. 再沿该方向确定最佳步长。

在当前 PGD 增广中：

| 优化概念 | PGD 对应含义 |
|---|---|
| 搜索方向 | 候选空间–时间模态 $`c(x,t)`$ |
| 步长 | 模态缩放系数 $`\alpha`$ |
| 目标函数 | 加权残差范数 $`\|r+\alpha c\|^2`$ |
| 线搜索结果 | 最优缩放系数 $`\alpha^\ast`$ |

因此，“最优缩放”本质上是一维解析线搜索。

---

## 15. 理想情况下是否仍需要最优缩放

在理想情况下，若能够同时满足以下条件：

- 一次性联合求解全部时间系数；
- 空间子问题和时间子问题与最终残差采用完全一致的离散；
- 正交化后重新严格优化；
- 所有积分权重和约束保持一致；
- 交替迭代达到真正的联合驻点；

则候选模态自身应接近最优尺度，此时通常有：

```math
\alpha^\ast
\approx
1.
```

因此，最优缩放不是 PGD 理论中必然存在的基本步骤。

它在当前实现中的作用主要是补偿：

```text
交替子问题收敛
```

与：

```text
完整时空残差联合最小化
```

之间的差异。

---

## 16. 与论文原始方法的关系

需要明确区分论文方法与当前实现中的稳定化措施。

论文描述了：

- PGD 空间–时间分离表示；
- 新模态的交替固定点构造；
- 模态增广；
- 正交化；
- 饱和参数控制。

但是，论文没有明确给出当前采用的标量最优缩放公式：

```math
\alpha^\ast
=
-
\frac{
\left\langle r,c\right\rangle
}{
\left\langle c,c\right\rangle
}.
```

因此，该步骤应准确表述为：

> 针对当前 Python 离散实现中，交替固定点构造的新模态可能因整体幅值不匹配而使残差增大的问题，在候选模态生成后增加的一维最优线搜索稳定化措施。

不能表述为：

> 论文原算法明确采用了最优缩放。

---

## 17. 推荐的技术表述

在汇报、开发日志或论文复现说明中，可采用以下表述：

> 新增 PGD 模态的交替固定点迭代能够获得稳定的空间–时间修正模式，但固定点收敛仅表示该候选模态在当前交替更新规则下趋于稳定，并不严格保证其原始幅值能够最小化完整时空域中的加权残差。特别是在已有多个模态、时间函数逐步更新以及候选模态正交化的条件下，空间子问题与时间子问题的局部最优并不等价于完整时空残差的联合最优。为保证模态增广后残差不增大，在候选模态方向上引入一维最优标量搜索，解析确定其最优贡献系数，并据此同步缩放时间幅值与时间导数。该处理保留候选模态的空间–时间形状，仅调整其在总解中的整体权重，从而提高 PGD 基底增广的稳定性。

更简洁的表述为：

> 固定点迭代确定新模态的空间–时间修正模式，最优缩放确定该模式在总解中的最佳贡献幅值。

## 18. 核心结论

本节内容可以概括为以下四点：

1. 固定点收敛不等于完整时空残差已经最小；
2. 新模态的空间–时间形状可以有效，但原始整体幅值仍可能过大或过小；
3. 最优缩放是在当前候选方向上的一维解析线搜索；
4. 该步骤保证新增模态不会使加权残差比不增广时更差。

最终可概括为：

```text
交替固定点迭代回答“修正模式是什么”；
最优缩放回答“该修正模式应加入多少”。
```

## 19. 后续扩展至海上风机模型时的注意事项

当 LATIN–PGD 扩展至海上风机疲劳分析时，最优缩放仍可能具有重要作用，因为：

- 空间自由度显著增加；
- 时间历程更长；
- 多种载荷频率耦合；
- 局部热点响应更复杂；
- 新模态与已有模态的相关性更强；
- 时间函数逐步更新误差可能累积。

后续应记录和检查：

- 每次增广的 $`\alpha^\ast`$；
- 缩放前后残差；
- 候选模态范数；
- 与已有模态的相关性；
- 负缩放系数出现的频率；
- 接近零缩放系数的模态是否应被拒绝；
- 最优缩放是否影响基底维数；
- 不同工况下缩放系数的稳定性。

若大量模态长期出现：

```math
\alpha^\ast
\ll
1
```

或频繁出现：

```math
\alpha^\ast
<
0,
```

则说明不仅是幅值问题，还可能需要重新检查：

- 时间更新方程；
- 空间子问题；
- 正交化顺序；
- 残差符号约定；
- 搜索方向；
- 加权内积；
- 时间积分离散。
