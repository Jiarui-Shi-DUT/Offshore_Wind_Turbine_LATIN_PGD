## 1. 本阶段的定位

本阶段没有直接进入 LATIN-PGD，而是先建立一个可信的 **海上风机塔筒全阶非线性循环参考模型（full-order reference model）**。后续判断 LATIN-PGD 是否正确、是否具有长周期计算优势，必须首先有一个经过充分验证的传统逐时间步有限元基准。

本阶段主要完成：

1. 建立 NREL 5 MW 塔筒二维纤维梁柱非线性模型；
2. 建立完整的正反向周期循环响应；
3. 建立逐循环位移、应力、塑性、硬化、损伤和 external work 诊断；
4. 新增塑性应变路径长度、累计塑性路径和净增量/路径比；
5. 通过“损伤耦合 / 关闭损伤”配对计算，将普通循环塑性与损伤驱动退化进行机制分离。

因此，本阶段的主要成果不是“预测真实海上风机寿命”，而是建立后续 LATIN-PGD 疲劳降阶分析所需的 **可重复、可诊断、可进行机制对照的全阶参考系统**。

## 2. 当前塔筒模型

当前模型以 NREL 5 MW 参考风机塔筒为基础，主要几何参数为：

- 塔筒高度：`H = 87.6 m`
- 底部外径：`D_base = 6.0 m`
- 顶部外径：`D_top = 3.87 m`
- 底部壁厚：`t_base = 27 mm`
- 顶部壁厚：`t_top = 19 mm`

结构采用二维 Euler-Bernoulli 梁柱描述，钢制环形截面通过纤维离散处理。

当前正式候选离散为：

- 轴向：40 个均匀梁单元；
- 每单元：4 个 Gauss 积分点；
- 每截面：周向 32 × 径向 2 = 64 根纤维；
- 更高精度参考方案可使用约 256 根纤维/截面。

机制验证阶段还使用过较低成本的：

```text
4 elements / 2 Gauss / 8 × 1 fibers
10 elements / 2 Gauss / 16 × 1 fibers
```

这些较粗离散主要用于快速机制分析，不能替代最终空间离散收敛研究。

## 3. 当前材料模型与内部变量

塔筒钢材采用一维粘塑性-损伤模型，材料状态中包含：

- 塑性应变 `plastic_strain`；
- 背应力相关内部变量 `alpha`；
- 各向同性硬化变量 `r_bar`；
- 损伤变量 `damage`。

模型包含：

- 弹性响应；
- 粘塑性流动；
- 随动硬化；
- 各向同性硬化及饱和；
- 损伤演化；
- 损伤与有效材料响应的耦合。

材料状态采用 RK4 时间积分，并嵌入结构层 Newton 迭代。

损伤演化可通过：

```text
k_damage
```

进行机制开关：

```text
k_damage > 0  -> 塑性 + 硬化 + 损伤耦合
k_damage = 0  -> 保持同样塑性/硬化，仅关闭损伤演化
```

这一设计是损伤机制分离分析的基础。

## 4. 当前采用的循环加载

现阶段采用简单、确定性的横向恒幅完全反向周期加载：

```text
F(t) = F_a sin(2πt/T)
```

每一循环的五个精确检查点为：

```text
0 -> +F_a -> 0 -> -F_a -> 0
```

当前加载形式的作用不是代表真实海上风机风浪荷载谱，而是构造一个：

- 周期严格可重复；
- 正负方向对称；
- 易于逐循环比较；
- 易于判断循环稳定、棘轮与退化；
- 适合验证 LATIN-PGD 长周期降阶能力

的标准数值基准。

### 下一阶段加载策略

现阶段 **不单独开展真实海上风机服役荷载谱构建**。实际荷载谱由课题组其他成员开展研究，待其形成成熟输入后，再接入当前模型。

因此，下一阶段仍保留简单恒幅周期循环加载，把研究重点集中在：

1. LATIN-PGD 在长周期循环中的降阶优势；
2. 纤维梁柱塔筒疲劳损伤演化。

这样可以避免在算法验证阶段把“复杂荷载影响”和“降阶算法误差”混在一起。

## 6. 为什么只看循环末塑性应变是不够的

完全反向零均值循环中，塑性变形可在正负方向交替发生。因此：

```text
循环内发生持续塑性变形
```

并不意味着：

```text
循环结束后的净塑性应变持续增大
```

正向塑性增长后，反向加载可产生反向塑性流动，使部分有符号塑性应变被抵消。因此循环末有符号塑性应变增量可能逐渐接近零。

如果只观察：

```text
plastic_strain(end)
```

容易误判为“塑性停止”。

因此本阶段进一步引入塑性应变路径诊断。

## 7. 塑性应变路径长度与累计塑性路径

对一个循环内的塑性应变历史：

```text
εp0, εp1, εp2, ..., εpn
```

定义每圈塑性应变路径长度：

```text
L_p = Σ |εp(i+1) - εp(i)|
```

它描述一个循环中实际发生的总塑性变化量。

有符号净塑性应变增量为：

```text
Δεp_net = εp(end) - εp(start)
```

始终有：

```text
|Δεp_net| <= L_p
```

进一步定义：

```text
R_net/path = |Δεp_net| / L_p
```

其解释为：

- `R ≈ 1`：塑性主要沿一个方向累积；
- `0 < R < 1`：同时存在循环塑性与一定净累积；
- `R -> 0`：正负塑性流动近似抵消，仍可能有明显塑性活动，但净棘轮很弱。

同时保存累计塑性路径：

```text
Σ L_p
```

该量后续可用于疲劳损伤累积、耗散分析以及 LATIN-PGD 长循环状态变量表示。

## 8. 为什么关闭损伤后会趋于稳定，即使仍存在塑性

这是本阶段最重要的物理解释之一。

关闭损伤并不等于关闭塑性。在：

```text
k_damage = 0
```

时，模型仍保留：

- 粘塑性流动；
- 随动硬化；
- 各向同性硬化；
- 反向塑性；
- Bauschinger 效应；
- 循环内塑性活动。

但是当前加载为：

```text
零均值 + 完全反向 + 对称恒幅
```

因此正负半周塑性具有较强相互抵消趋势。随着循环进行：

1. 随动硬化使屈服中心逐渐调整；
2. 各向同性硬化逐渐接近饱和；
3. 正负方向塑性流动逐渐形成重复路径；
4. 每圈净塑性增量趋小；
5. 残余位移不再持续单向增长；
6. 应力范围和位移范围趋于稳定。

此时完全可能同时满足：

```text
每圈塑性路径长度 L_p > 0
```

而：

```text
|Δεp_net| / L_p -> 很小
```

也就是说：

> 材料仍在稳定滞回环中反复发生正、负塑性流动，但这些塑性流动在循环结束时基本相互抵消。

因此必须严格区分：

```text
存在循环塑性
```

和：

```text
存在持续单向棘轮累积
```

同样，累计塑性路径持续增加，也不意味着残余塑性应变必须持续增加。

这一点对高周疲劳尤其重要，因为疲劳损伤可能与“累计经历的循环塑性活动”更相关，而不只是与循环末净塑性应变相关。

## 9. external work 的当前解释边界

多循环模块还计算每圈力-位移路径积分，即 external work。

在尚未形成闭合稳定循环时，它不能自动等价为纯材料耗散，因为循环起点与终点之间仍可能存在内部储能变化。

因此当前代码和论文表述中应继续使用：

```text
external work
```

而不是在所有阶段直接称为：

```text
dissipation
```

只有在闭合稳定循环或完成严格能量分解后，才适合进一步解释为耗散能。

## 10. 损伤机制分离方法

核心模块：

```text
examples/nonlinear_tower_damage_mechanism_probe.py
```

建立两组严格配对分析。

### Case A：塑性-损伤耦合

```text
k_damage = 默认值
```

包含完整：

```text
塑性 + 硬化 + 损伤
```

### Case B：关闭损伤

```text
k_damage = 0
```

仍保留：

```text
塑性 + 随动硬化 + 各向同性硬化
```

仅关闭损伤演化。

两组保持一致的：

- 塔筒几何；
- 空间离散；
- 纤维截面；
- 荷载历史；
- 时间离散；
- 塑性参数；
- 硬化参数；
- Newton 求解控制。

同时由耦合损伤算例确定临界纤维物理位置，并强制关闭损伤算例使用同一根物理纤维。

因此比较反映的是同一材料点在有、无损伤演化条件下的差别，而不是“两个不同最大值位置”的差别。

## 15. 损伤增量没有进入稳定平台

20 圈最大损伤达到：

```text
D_max ≈ 0.053033
```

逐圈最大损伤增量：

```text
cycle 1 : 0.0025359
cycle 2 : 0.0024060
cycle 3 : 0.0024049
cycle 5 : 0.0024512
cycle 10: 0.0026085
cycle 15: 0.0027865
cycle 20: 0.0029867
```

第 3 圈附近达到较小值，随后逐渐增加。从第 3 圈至第 20 圈，`ΔD` 增加约 24%。

当前结果支持如下数值正反馈链：

```text
损伤增长
  ↓
局部材料/截面有效响应改变
  ↓
塑性路径与整体响应改变
  ↓
进一步促进损伤
```

因此当前可表述为：

> 普通循环塑性和硬化在关闭损伤时可以逐渐形成近稳定循环，而持续损伤演化会破坏这种稳定趋势并驱动结构响应继续退化。

仍需强调：这是 **数值机制分离结果**，并不等同于已经证明真实塔筒一定发生物理失稳。

# 21. 下一阶段工作重点

下一阶段仍采用：

```text
简单恒幅完全反向横向周期循环
```

作为标准输入，不先增加真实复杂荷载谱。

## 主线 A：验证 LATIN-PGD 在长周期循环中的降阶优势

核心目标：

> 将当前传统逐时间步塔筒模型作为 reference solution，在相同材料、结构和循环加载下建立 LATIN-PGD 解，并同时比较精度与计算成本。

重点内容包括：

### A1. 固定 full-order reference

当前 nonlinear tower solver 继续作为全阶参考，不在 LATIN-PGD 初期反复修改基础本构和结构求解器。

### A2. 研究 LATIN-PGD 变量分离

研究塔筒状态变量的低秩表示，例如：

```text
X(t, x) ≈ Σ Ti(t) Xi(x)
```

并针对：

```text
σ, εp, α, r_bar, D
```

判断是共享模式还是分别构造时间函数和空间模式。

### A3. 扩展循环数量

从当前几十圈逐步增加至：

```text
10^2
10^3
甚至更高数量级
```

重点统计：

- 所需 PGD 模态数；
- LATIN 迭代次数；
- 模态数随循环数的增长；
- full-order CPU 时间；
- LATIN-PGD CPU 时间；
- 内存占用；
- 加速比。

### A4. 精度评价

至少比较：

- 塔顶位移历史；
- 位移范围；
- 临界纤维应力；
- 塑性应变；
- 塑性路径；
- 背应力；
- `r_bar`；
- 损伤；
- 塔筒高度方向损伤场。

不能只用塔顶位移作为 LATIN-PGD 正确性的唯一证据。

### A5. 最终要回答的核心问题

> 当循环数量很大时，LATIN-PGD 能否在保持可接受误差的同时，使计算成本不再按传统“时间步数 × 空间自由度”的方式快速增长？

这是将 LATIN-PGD 推广到海上风机塔筒高周疲劳问题的核心价值。

## 主线 B：构建纤维梁柱塔筒疲劳损伤演化结果

### B1. 塔筒高度方向损伤

输出：

```text
D(z, N)
```

即不同循环数下沿塔筒高度的损伤分布。

### B2. 周向纤维损伤

对关键截面输出：

```text
D(θ, N)
```

观察不同周向纤维的损伤差异。

### B3. 临界区域演化

跟踪：

- 临界单元；
- 临界 Gauss 点；
- 临界纤维；
- 临界位置是否随循环迁移。

### B4. 塑性与损伤关系

联合分析：

```text
塑性路径长度
累计塑性路径
external work
damage increment
```

建立循环塑性活动与损伤增长之间的联系。

### B5. 整体退化指标

建立：

```text
塔顶位移范围
等效循环刚度
应力范围
残余位移
损伤
```

之间的关系，形成：

```text
循环数 N
  ↓
局部塑性路径累积
  ↓
局部损伤增长
  ↓
截面/结构有效刚度下降
  ↓
塔筒整体柔度增加
```

这一完整演化链条。

# 22. 下一阶段建议技术顺序

为避免 LATIN-PGD 与塔筒全阶模型同时大规模修改导致问题难以定位，建议按以下顺序推进：

```text
Step 1  冻结当前 full-order reference model
        ↓
Step 2  建立塔筒高度方向/周向疲劳损伤场后处理
        ↓
Step 3  建立长循环 full-order benchmark
        ↓
Step 4  将 LATIN-PGD 接入相同塔筒问题
        ↓
Step 5  逐变量验证 LATIN-PGD 与 full-order 一致性
        ↓
Step 6  增加循环数量
        ↓
Step 7  统计模态数、迭代次数、CPU 时间与加速比
        ↓
Step 8  形成海上风机塔筒 LATIN-PGD 高周疲劳完整算例
```

这里建议先完成 Step 2，再开始真正的 LATIN-PGD 长循环塔筒求解。

原因是：

> LATIN-PGD 最终不仅需要复现塔顶位移，还必须复现塔筒内部的塑性与损伤场。

因此应该先明确 full-order 模型中“究竟要比较哪些疲劳场变量”，再设计 LATIN-PGD 的状态变量分离、误差指标和结果输出。
