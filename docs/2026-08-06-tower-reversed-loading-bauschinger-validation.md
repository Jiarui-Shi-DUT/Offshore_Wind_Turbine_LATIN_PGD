## 3. 零均值完全反向荷载

### 3.1 荷载定义

反向荷载采用：

$$F(t)=F_a\sin(\omega t),\qquad \omega=\frac{2\pi}{T}.$$

其中：

- $F_a$：塔顶水平力幅值；
- $T$：循环周期；
- $\omega$：圆频率。

荷载特征为：

$$F_{\max}=+F_a,$$

$$F_{\min}=-F_a,$$

$$F_{\mathrm{mean}}=0,$$

$$R_F=\frac{F_{\min}}{F_{\max}}=-1.$$

### 3.2 时间离散

每个循环的时间增量数要求：

```text
increments_per_cycle >= 4
```

并且：

```text
increments_per_cycle % 4 == 0
```

从而保证以下五个关键时刻都属于离散时间点：

| 归一化时间 | 荷载 |
|---:|---:|
| $t/T=0$ | $0$ |
| $t/T=0.25$ | $+F_a$ |
| $t/T=0.50$ | $0$ |
| $t/T=0.75$ | $-F_a$ |
| $t/T=1.00$ | $0$ |

程序对理论零点和正负峰值执行机器精度范围内的数值吸附，避免浮点正弦计算产生极小的非零残量。

## 4. 反向循环分析中的完整纤维状态

每个纤维材料点保存四个内部变量：

$$\mathbf q_f= \left[ \varepsilon_f^p,\, \alpha_f,\, \bar r_f,\, D_f \right].$$

其中：

- $\varepsilon_f^p$：塑性应变；
- $\alpha_f$：随动硬化内部变量；
- $\bar r_f$：各向同性硬化内部变量；
- $D_f$：损伤变量。

背应力定义为：

$$\beta_f=C\alpha_f.$$

反向循环分析不仅记录纤维应力和塑性应变，还记录完整状态数组：

```text
fiber_states[
    time_index,
    element_index,
    gauss_index,
    fiber_index,
    state_index
]
```

状态分量约定为：

```text
state_index = 0: plastic strain
state_index = 1: alpha
state_index = 2: r_bar
state_index = 3: damage
```

这使得反向屈服面平移、随动硬化和各向同性硬化可以分别分析。

## 5. 固定临界纤维选择

反向循环中不能在每个时刻都重新选择“当前最大应力纤维”，否则得到的历史可能来自不同材料点，无法代表真实的路径相关响应。

本阶段采用一个固定临界纤维：

1. 首先计算完整时间历史中的峰值损伤；
2. 选择峰值损伤最大的固定纤维；
3. 若全过程损伤均为零，则选择峰值绝对塑性应变最大的固定纤维；
4. 后续应力、应变、塑性、背应力和屈服函数均提取自该固定材料点。

标准反向循环分析得到：

```text
Element:
1

Gauss point:
1

Fiber:
13

Height:
1.851206 m

Section y-coordinate:
-2.945089 m
```

该纤维位于塔底附近的外缘区域，符合悬臂塔筒底部弯矩最大的力学规律。

需要注意：

> 在当前截面坐标和曲率符号约定下，正向塔顶水平力使该负 $y$ 外缘纤维受压，因此其应力为负；反向塔顶力使其受拉，因此其应力转为正。这是截面符号约定的结果，不是荷载或应力方向错误。

## 7. 包辛格效应的理论判据

### 7.1 当前屈服函数

当前一维黏塑性损伤模型采用：

$$f= \left| \frac{\sigma}{1-D}-\beta \right| + \frac{a\beta^2}{2C} -R-\sigma_y.$$

其中：

- $\beta=C\alpha$：背应力；
- $R$：各向同性硬化力；
- $D$：损伤变量；
- $\sigma_y$：初始屈服应力。

黏塑性乘子为：

$$\dot\lambda=K^{-n}\langle f\rangle_+^n.$$

因此：

```text
f <= 0:
no viscoplastic flow

f > 0:
viscoplastic flow develops
```

### 7.2 初始屈服

初始状态满足：

$$\beta=0,\qquad R=0,\qquad D=0.$$

因此初始屈服条件为：

$$|\sigma|=\sigma_y.$$

当前材料参数给出：

$$|\sigma_{\mathrm{y,initial}}|=80\ \mathrm{MPa}.$$

### 7.3 反向正应力屈服极限

本算例先使固定临界纤维进入负应力塑性状态，再卸载并向正应力方向反向加载。

在正向反向屈服时：

$$\frac{\sigma}{1-D}-\beta>0.$$

令 $f=0$，可得：

$$\frac{\sigma_{\mathrm{rev}}}{1-D} -\beta + \frac{a\beta^2}{2C} -R-\sigma_y=0.$$

因此：

$$\sigma_{\mathrm{rev}} = (1-D) \left[ \sigma_y+R -\frac{a\beta^2}{2C} +\beta \right].$$

### 7.4 不含随动硬化的反事实极限

为了单独识别包辛格效应，保持同一时刻的：

- 各向同性硬化力 $R$；
- 损伤 $D$；

但令：

$$\beta=0.$$

则反事实反向屈服极限为：

$$\sigma_{\mathrm{rev}}^{\beta=0} = (1-D)(\sigma_y+R).$$

### 7.5 随动硬化导致的反向屈服降低量

定义：

$$\Delta\sigma_{\mathrm{B}} = \sigma_{\mathrm{rev}}^{\beta=0} - \sigma_{\mathrm{rev}}.$$

代入可得：

$$\Delta\sigma_{\mathrm{B}} = (1-D) \left[ -\beta+\frac{a\beta^2}{2C} \right].$$

当反向加载前：

$$\beta<0,$$

则通常有：

$$\Delta\sigma_{\mathrm{B}}>0.$$

这表示背应力导致相反方向的屈服应力降低，即包辛格效应。

时间离散由反向循环验证中的 40 个增量加密到 160 个增量，以减小屈服函数过零点的插值误差。

### 8.2 屈服点识别方法

对固定临界纤维计算每个时刻的屈服函数 $f(t)$。

在指定加载分支内寻找第一组：

$$f_i\le0,$$

$$f_{i+1}>0.$$

然后在线性插值意义下求解：

$$f(t_y)=0.$$

插值得到：

- 屈服时刻；
- 塔顶力；
- 固定纤维应力；
- 塑性应变；
- 背应力。

该方法用于：

1. 初始加载分支 $0\le t/T\le0.25$；
2. 反向加载分支 $0.5\le t/T\le0.75$。

### 8.3 数值识别结果

| 屈服分支 | $t/T$ | 塔顶力/MN | 纤维应力/MPa | 塑性应变 | 背应力/MPa |
|---|---:|---:|---:|---:|---:|
| 初始加载 | 0.120449 | 0.686493 | -80.000003 | -5.941845×10⁻¹⁰ | -0.000003 |
| 反向加载 | 0.605070 | -0.613181 | +79.311656 | -1.265753×10⁻⁴ | -0.685265 |

$$|\sigma_{\mathrm{y,initial}}| = 80.000003\ \mathrm{MPa}.$$

反向屈服应力幅值为：

$$|\sigma_{\mathrm{y,reverse}}| = 79.311656\ \mathrm{MPa}.$$

实际识别到的初始—反向变化为：

$$\Delta\sigma_{\mathrm{observed}} = 80.000003-79.311656 = 0.688347\ \mathrm{MPa}.$$

### 8.4 反向加载前状态

在第一次回到零塔顶力，即：

$$t/T=0.5,$$

固定临界纤维状态为：

| 变量 | 数值 |
|---|---:|
| 背应力 $\beta$ | -0.685265 MPa |
| 各向同性硬化力 $R$ | 0.007594 MPa |
| 损伤 $D$ | 0 |

因此反向屈服同时受到：

- 负背应力引起的屈服面平移；
- 小幅各向同性硬化；
- 当前算例中该时刻可忽略的损伤影响。

### 8.5 理论反向屈服极限

代入当前状态得到：

$$\sigma_{\mathrm{rev}} = 79.311656\ \mathrm{MPa}.$$

在保持相同 $R$ 和 $D$、但令 $\beta=0$ 时：

$$\sigma_{\mathrm{rev}}^{\beta=0} = 80.007594\ \mathrm{MPa}.$$

因此背应力导致的纯随动硬化降低量为：

$$\Delta\sigma_{\mathrm{B}} = 80.007594-79.311656 = 0.695938\ \mathrm{MPa}.$$

相对降低比例为：

$$\eta_{\mathrm{B}} = \frac{0.695938}{80.007594} \times100\% = 0.869839\%.$$

### 8.6 理论与数值一致性

理论预测的反向屈服应力为：

$$79.311656\ \mathrm{MPa}.$$

数值屈服函数过零识别结果为：

$$79.311656\ \mathrm{MPa}.$$

两者在当前输出精度下完全一致。

这验证了：

1. 固定纤维完整状态记录正确；
2. 背应力 $\beta=C\alpha$ 的提取正确；
3. 各向同性硬化力 $R$ 的计算正确；
4. 损伤修正进入屈服极限的方式正确；
5. 反向屈服面平移公式正确；
6. 屈服函数过零插值正确；
7. 当前模型确实产生了可定量识别的包辛格效应。

## 9. 为什么观测降低量与纯包辛格降低量不完全相同

本算例中：

$$\Delta\sigma_{\mathrm{observed}} = 0.688347\ \mathrm{MPa},$$

而：

$$\Delta\sigma_{\mathrm{B}} = 0.695938\ \mathrm{MPa}.$$

两者相差：

$$0.007591\ \mathrm{MPa}.$$

主要原因是观测到的反向屈服应力同时受到：

- 各向同性硬化；
- 背应力平移；
- 非线性随动硬化项；
- 损伤；
- 时间离散；
- 黏塑性率效应和超应力；

共同影响。

在当前结果中，各向同性硬化力为：

$$R=0.007594\ \mathrm{MPa},$$

其量级与两种降低量之间的差值基本对应。

因此不能简单采用：

```text
initial yield magnitude
minus
reverse yield magnitude
```

作为纯包辛格效应。

本阶段采用的反事实比较：

```text
same R
same D
same material state level
only set beta = 0
```

能够更严格地隔离随动硬化造成的屈服面平移。
